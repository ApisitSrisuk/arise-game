# ผู้ปลุกพลัง (Arise)

เกม RPG พิกเซลในเบราว์เซอร์ แนวฮันเตอร์ปลุกพลังในโลกยุคปัจจุบัน ลงดันเจี้ยนผ่านเกต สะสมฮีโร่ด้วยกาชา และแต่งตัวละครได้อิสระ ตัวละคร มอนสเตอร์ ฮีโร่ เสียง และเพลงทั้งหมดสร้างขึ้นใหม่ด้วยโค้ด ไม่ได้ใช้ภาพ เสียง หรือบทจากงานต้นฉบับใด

**เล่นได้ที่:** https://apisitsrisuk.github.io/arise-game/

## วิธีรัน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 แล้วเล่นได้เลย เกมบันทึกความคืบหน้าไว้ใน localStorage ของเบราว์เซอร์ เซฟจากเวอร์ชันเก่ายังใช้ต่อได้ อาวุธและเกราะเดิมจะแปลงเป็นไอเทมสวมใส่ให้อัตโนมัติ

สร้างไฟล์สำหรับเผยแพร่ด้วย `npm run build` (ผลลัพธ์อยู่ในโฟลเดอร์ `dist`) เมื่อ push ขึ้น `main` แล้ว GitHub Actions จะ build และ deploy ขึ้น GitHub Pages ให้เอง โดยต้องตั้ง Settings → Pages → Source เป็น **GitHub Actions** ก่อนหนึ่งครั้ง

## ระบบในเกม

- **สร้างตัวละคร:** ตั้งชื่อ เลือกทรงผม สีผม สีผิว สีตา และภูมิหลังที่ให้โบนัสต่างกัน
- **สุ่มอาชีพและสกิล:** อาชีพปกติ อาชีพลับ และอาชีพที่ต้องทำเงื่อนไขลับ สกิลทุกอันมีเกรด C ถึง S
- **อัปสเตตัสแล้วเก่งขึ้นทุกอาชีพ:** STR เพิ่ม ATK ให้ทุกอาชีพ INT เพิ่มพลังสกิล เมื่อค่าสถานะใดถึง 20 / 40 / 70 จะปลดล็อกความสามารถพิเศษของค่านั้น
- **ตื่นรู้ตามสายที่ฝึก:** ที่เลเวล 20 เลือกได้ระหว่างสายดั้งเดิมของอาชีพ กับสายผสมที่เปิดเมื่อค่าสถานะรองถึง 40 เช่น นักธนูที่อัป INT ตื่นรู้เป็น "นักธนูเวท" แต่ละสายมีพลังและสกิลสุดยอดของตัวเอง
- **คลาสรอง:** ปลดล็อกที่เลเวล 10 เลือก 1 จาก 3 ตัวเลือกสุ่ม ได้โบนัสและสกิลเพิ่ม ถ้าเข้าคู่กับอาชีพหลักจะแรงขึ้น
- **แต่งตัว:** ชุดไม่ผูกกับอาชีพ มีช่องสวมใส่ 4 ช่อง (อาวุธ ศีรษะ ชุด แผ่นหลัง) มีทั้งเสื้อผ้าสมัยใหม่และชุดเกราะจากดันเจี้ยน ลองสวมก่อนซื้อได้ ไอเทมดรอปจากบอสและหีบสมบัติ
- **อัญเชิญฮีโร่:** กาชาฮีโร่ ★1 ถึง ★5 ใช้คริสตัล มีการันตี ★5 ได้ตัวซ้ำจะทะลวงขีดจำกัด ฮีโร่ในทีมช่วยสู้ทุกเทิร์นตามบทบาท (จู่โจม เวท แนวหน้า ฟื้นฟู สนับสนุน)
- **นิสัยฮีโร่:** ฮีโร่ทุกตัวที่อัญเชิญได้จะสุ่มนิสัย เช่น กล้าหาญ ขี้ขลาด ขี้เกียจ ภักดี เจ้าเล่ห์ ซึ่งมีผลต่อการต่อสู้จริง
- **เมือง:** ส่งฮีโร่ไปทำงานใน 9 สิ่งก่อสร้าง ผลิตอาหาร ไม้ หิน เหล็ก ทอง ยา คริสตัล และอุปกรณ์ ฮีโร่กินอาหารทุกวัน ยอมทำงานหรือไม่ขึ้นกับนิสัย ตัวที่ดื้องานย่อยเป็นเศษวิญญาณได้ อัปศาลากลางเพื่อเปิดสิ่งก่อสร้างใหม่
- **เลเวลฮีโร่และตู้เรตอัป:** ฮีโร่เก่งขึ้นจากการต่อสู้และทำงาน ที่เลเวล 10 ปลดสกิลประจำบทบาท ทุกสัปดาห์มีฮีโร่ ★4/★5 เรตอัป
- **สมาคมฮันเตอร์:** กระดานภารกิจ 3 อย่างต่อวัน ความสำเร็จ 19 รายการ และฉายาที่ให้โบนัสเล็กๆ
- **เกตประจำวันและเกตแตก:** แต่ละวันมีเกตหนึ่งแห่งที่ได้ EXP และทอง ×1.5 บางวันมีเกตที่กำลังจะแตก ถ้าไม่ล้มบอสภายใน 3 วัน มอนสเตอร์จะบุกเมือง
- **ออโต้และกวาดเกต:** เปิดออโต้ในการต่อสู้ได้ เกตที่เคยเคลียร์และเลเวลห่างพอ กวาดรับรางวัลทันทีได้
- **ขีดจำกัดถัดไป:** ตื่นรู้ขั้นที่ 2 ที่เลเวล 40 หลังล้มบอสแรงก์ S และจุติใหม่ที่เลเวล 50 เพื่อรับโบนัสถาวร
- **ของใช้:** ทำภารกิจรายวันได้ในคลิกเดียว มียาล้างแต้มสถานะ ขายอุปกรณ์ที่ไม่ใช้ได้ 40% ของราคาร้าน
- **สตามินารายวัน:** เข้าเกต เดินห้อง ฝึก และทำกิจกรรมต้องใช้สตามินา ถ้าเหลือน้อยจะเหนื่อยล้าหรือหมดแรง
- **ดันเจี้ยนสุ่ม:** เกตแรงก์ E ถึง S แต่ละครั้งสุ่มห้องและความผิดปกติของเกต
- **กองทัพเงา:** อาชีพที่สกัดเงาได้สั่ง ARISE ดึงเงาบอสมาเป็นทหาร
- **เสียง:** เอฟเฟกต์และเพลงประกอบสังเคราะห์สดด้วย Web Audio เปิดปิดและปรับระดับเสียงรวม เอฟเฟกต์ และเพลงแยกกันได้ที่ปุ่มมุมขวาบน

## โครงสร้างโค้ด

- `src/game/` กลไกเกม (state, กฎการคำนวณ, การต่อสู้) และข้อมูล (อาชีพ สกิล ไอเทม ฮีโร่ คลาสรอง)
- `src/components/` หน้าจอ React
- `src/arena/` ฉากต่อสู้บน Canvas
- `src/art/` ตัววาดสไปรต์พิกเซล
- `src/audio/` เสียงและเพลง
- `gallery.html` และ `design.html` เป็นหน้าสำหรับดูสไปรต์ระหว่างพัฒนา (ไม่รวมอยู่ใน build)
- `node scripts/playtest.mjs [รอบ] [วัน]` จำลองการเล่นทั้งเกมโดยไม่ต้องเปิดเบราว์เซอร์ ใช้เช็กสมดุลและหาบั๊ก
- เติม `?slot=ชื่อ` ท้าย URL เพื่อเล่นด้วยเซฟแยก ไม่กระทบเซฟหลัก
